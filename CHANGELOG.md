# Changelog

All notable changes to this project are documented here.

## Deprecated – 2025-09-15

- Project deprecated in favor of baldrick-broth (orchestrator) and baldrick-reserve (templates).
- Rationale: decouple template updates from CLI releases and enable easier local iteration before promoting templates.
- Replacement:
  - baldrick-broth: https://github.com/flarebyte/baldrick-broth
  - baldrick-reserve: https://github.com/flarebyte/baldrick-reserve
- No further releases are planned for this package.
